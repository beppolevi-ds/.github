# beppolevi-desarrollosoftware

Este grupo nace del interés de los alumnos en la busqueda de realizar prácticas sobre conocimientos complementarios a la carrera. En un principio, se busca trabajar sobre temas como: infraestructura de red/servidores, devops, LMS e inteligencia artificial.

La documentación busca incentivar a futuras cohortes continuar con el desarrollo de los proyectos así como mejorarlos.
